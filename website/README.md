# Oridium Interface Website

Black-themed landing page with snowflake animation.

## Preview

Open `index.html` in your browser, or enable **GitHub Pages**:

1. Go to repo **Settings** → **Pages**
2. Source: Deploy from branch
3. Branch: `main` → folder `/website`
4. Save

Then it will be live at:
`https://idebob.github.io/Oridium-Interface/`

## Features

- Pure black UI
- Falling snowflake animation
- Copy Oridium Script box with animated copy button
- Feature grid
- Links to GitHub, Tutorials, and API Docs
