# Keybinds

Default keybinds for Oridium Interface.

| Feature          | Default Key | Notes                          |
|------------------|-------------|-------------------------------|
| Toggle UI        | **End**     | Shows / hides the entire menu |
| Aimbot           | **Q**       | Toggle on/off                 |
| ESP              | **M**       | Toggle on/off                 |

---

## Changing Keybinds

Most keybinds can be changed directly inside the UI:

1. Open the menu (press **End**)
2. Go to the feature
3. Click the keybind box next to the toggle
4. Press the new key you want

The new keybind is saved automatically.
