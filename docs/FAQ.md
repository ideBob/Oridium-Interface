# Frequently Asked Questions

### Does this work on mobile?
No. Oridium requires a PC executor that supports the Drawing library and metatable hooks.

### Why is Silent Aim not hitting?
Silent Aim depends on how the game handles shooting. Some games use custom systems that the current hook may not catch. Try toggling it off and on again.

### Can I change the FOV of the Aimbot?
Currently the Aimbot FOV is fixed at 360 (full screen). You can request this as a future feature.

### Do the Good/Bad Boy marks stay after I rejoin?
The marks are only visual while the script is running. The lists (`GoodBoys` / `BadBoys`) stay in memory until you leave the game or clear them.

### Is my config saved?
Yes. Settings are saved using Linoria's SaveManager. They should load automatically next time you run the script.

### The UI disappeared. How do I get it back?
Press the **End** key.

### Can I use this on other games?
Some features (ESP, Aimbot, High Jump, etc.) work on many games. Triggerbot weapon names and Silent Aim are more Da Hood oriented.
