# Oridium Interface - Mobile Version

Optimized for mobile executors using **Kavo UI Library**.

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ideBob/Oridium-Interface/main/Mobile/Oridium-Mobile.lua"))()
```

## Features

- Aimbot
- Silent Aim
- Triggerbot
- ESP + Aimviewer
- High Jump
- Player Customization (R15 Load All)
- Good Boy / Bad Boy system
- Bigger UI (better for mobile)

## Notes

- Uses Kavo UI (much better scaling on mobile than Linoria)
- Recommended for Android executors (Delta, Codex, Arceus X, etc.)
