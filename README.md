### ✨ Features

| | Feature | Description |
|:-:|---------|-------------|
| 🎯 | **Aimbot** | Smooth camera lock |
| 🔇 | **Silent Aim** | Bullet redirection |
| 🔫 | **Triggerbot** | Auto fire in FOV |
| 👁️ | **ESP** | Boxes, Health, Distance |
| 👀 | **Aimviewer** | See where players look |
| 🦘 | **High Jump** | Adjustable JumpPower |
