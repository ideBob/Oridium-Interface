### Features

- **Aimbot** (Smooth + Keybind Q)
- **Silent Aim**
- **Triggerbot** with Mouse FOV
- **ESP** (Box, Healthbar, Distance)
- **Aimviewer**
- **High Jump** + Slider
- **Anti Detection**
- **Good Boy / Bad Boy** system with visual marks
- **RGB UI Accent**
- Custom Thunderbolt Intro Animation
- Config Saving
